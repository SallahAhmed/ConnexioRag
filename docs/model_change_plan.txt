# Implementation Plan: Switch Generative LLM to Local Ollama Model

This plan outlines the steps required to switch the application's text generation and embedding models to your local models managed by Ollama (qwen:4b and nomic-embed-text:latest), without deleting any of the existing remote providers (Cohere, OpenAI) so that you can easily switch back in the future.

## Proposed Changes

1. **Update .env Configuration**:
    - Change OPENAI_GENERATION_API_URL from the remote ngrok tunnel to Ollama's local URL: http://localhost:11434/v1
    - Change GENERATION_MODEL_ID from "gemma4:e4b" to "qwen:4b"
    - Keep existing GENERATION_BACKEND, EMBEDDING_BACKEND, and API keys for future use.

## Verification

- The application uses the local Ollama server for text generation.
- The embedding model continues to use the local Ollama server (nomic-embed-text).
- All API keys for OpenAI and Cohere remain in the .env file for easy switching.
