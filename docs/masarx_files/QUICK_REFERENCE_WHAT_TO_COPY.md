## 🎯 Step-by-Step: What to Tell Your Colleague

### Phase 1: Copy Boilerplate Files
1. **"Copy the entire `alembic/` directory structure** from `src/models/db_schemas/connexio/`"
2. **"Copy `src/helpers/config.py`** and add POSTGRES variables"
3. **"Copy these exact 5 packages** from requirements.txt: SQLAlchemy, asyncpg, alembic, psycopg2-binary, pgvector"

### Phase 2: Understand the Patterns
1. **"Study `connexio_base.py`"** - shows how SQLAlchemy base is created
2. **"Study `data_chunk.py`"** - shows pattern for models with relationships and vectors
3. **"Study `asset.py`"** - shows pattern for models with JSON columns

### Phase 3: Customize for Your Project
1. **"Update `alembic.ini`"** - change database URL to YOUR database
2. **"Update `alembic/env.py`"** - change import path to YOUR schemas location
3. **"Create your own model files"** in `schemas/` following the patterns
4. **"Update docker-compose.yml"** - change credentials to match YOUR .env

### Phase 4: Generate Migrations & Deploy
1. **"Run `alembic revision --autogenerate -m 'initial_commit'`"** to generate first migration
2. **"Review generated migration"** in `alembic/versions/`
3. **"Run `alembic upgrade head`"** to apply migrations
4. **"Start your app"** and database will be ready

## 💡 Key Points to Emphasize

| What | Where in Connexios | Why Important |
|-----|-------------------|---------------|
| **pgvector extension** | Need to add to first migration | Can't use Vector columns without it |
| **Vector column type** | `data_chunk.py` line: `Column(Vector(1024))` | Must match embedding model dimensions |
| **Foreign key patterns** | `data_chunk.py` lines with `ForeignKey()` | Maintains data integrity |
| **Relationships** | `data_chunk.py` lines with `relationship()` | Enables ORM queries across tables |
| **Indexes** | `data_chunk.py` __table_args__ | Improves query performance |
| **Timestamps** | All models have `created_at`, `updated_at` | Audit trail & data tracking |
| **UUIDs** | All models use `UUID()` for uniqueness | Better than auto-increment IDs |

## ⚠️ Common Mistakes to Avoid

1. **"Don't" forget to import SQLAlchemyBase** in each model file
2. **"Don't"** hardcode database URLs in code - use .env
3. **"Don't"** modify alembic/versions/ files manually - let alembic auto-generate them
4. **"Don't"** forget pgvector extension in first migration
5. **"Don't"** use Vector columns without specifying dimension: `Vector(1024)`
6. **"Don't"** forget to run `alembic upgrade head` before starting the app
