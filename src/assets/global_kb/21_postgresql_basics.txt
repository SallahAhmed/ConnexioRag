PostgreSQL is a powerful open-source relational database management system known for its reliability, extensibility, and standards compliance. It has been actively developed for over three decades and is widely considered the most advanced open-source database available. PostgreSQL supports ACID transactions, which ensure that database operations are atomic, consistent, isolated, and durable. It is the primary database backend for the Connexios RAG and MasarX Agent.

Key PostgreSQL features include full SQL compliance with advanced query capabilities including complex joins, subqueries, window functions, common table expressions, and recursive queries. It supports a wide range of data types beyond standard SQL including JSON and JSONB for flexible document storage, arrays, hstore for key-value pairs, geometric types for spatial data, and network address types. PostgreSQL extensions add even more functionality. The pgvector extension enables vector similarity search which is used by Connexios for semantic search over document embeddings. PostGIS adds geographic object support for location-based queries. PostgreSQL supports indexing methods including B-tree, Hash, GiST, GIN, and BRIN indexes that optimize query performance for different data types and access patterns.

PostgreSQL uses a client-server architecture with configurable authentication methods including password-based and certificate-based authentication. Connection pooling can be managed through tools like PgBouncer, which is particularly important for serverless environments like Neon.tech where connection limits apply. In the Connexios architecture, PostgreSQL on Neon.tech stores project metadata, assets, data chunks, chat sessions, vector embeddings, and MasarX notifications. The vector collections are stored as separate tables with names like collection_1024_42, each containing text content, vector embeddings, metadata, and chunk IDs. These collections use HNSW indexes for fast approximate nearest neighbor search and GIN trigram indexes for text similarity search. The hybrid search combines vector similarity and text similarity using Reciprocal Rank Fusion.
