Color theory is a framework for understanding how colors interact and how to use them effectively in design. It provides practical guidance for choosing and combining colors to create visually appealing and effective designs. Understanding color theory is essential for UI designers, graphic designers, and anyone creating visual content.

The color wheel is the foundation of color theory and shows relationships between colors. Primary colors (red, blue, yellow) cannot be created by mixing other colors. Secondary colors (green, orange, purple) are created by mixing two primary colors. Tertiary colors are created by mixing a primary with a secondary color. Color schemes based on the wheel include complementary colors which are opposite each other and create high contrast, analogous colors which are next to each other and create harmony, triadic colors which are evenly spaced and create vibrant contrast, and monochromatic which uses variations of a single color for a cohesive look.

Color psychology associates different colors with emotions and meanings, though these associations can vary by culture. Blue is associated with trust, professionalism, and calmness, making it popular for corporate and technology brands. Red conveys urgency, excitement, and passion, often used for calls to action. Green represents growth, health, and nature, common for environmental and financial products. Yellow suggests optimism and warmth but should be used sparingly as it can cause eye strain. Purple implies creativity and luxury. Orange combines red's energy with yellow's friendliness. Black conveys sophistication and power. White represents cleanliness and simplicity. Good color design considers accessibility by ensuring sufficient contrast ratios between text and backgrounds as defined by WCAG guidelines, using tools like WebAIM's contrast checker. A typical UI color palette includes a primary color, secondary color, neutral colors for backgrounds and text, and accent colors for highlighting specific elements.
