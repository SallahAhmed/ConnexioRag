Connexio is a collaborative project platform that connects learners and builders to create real software projects in intelligent teams. It bridges the gap between education and real-world experience by providing a structured environment where users can form teams, manage projects, learn new skills, and build production-quality software together. The platform is designed to serve four main user personas: students who want hands-on project experience, early-career professionals looking to build their portfolios and network, educators who need a practical platform for teaching software development, and companies seeking to identify and recruit talented developers through real project work.

The platform consists of three integrated backend services working together. The main API backend handles core operations including user authentication, project management, task tracking, file uploads, and social features. The Connexios RAG (Retrieval-Augmented Generation) engine powers intelligent chat by searching indexed documents, combining them with live project data, and generating context-aware answers. The MasarX Agent handles autonomous project management including task creation with human-in-the-loop approval, team matching, document generation for READMEs and retrospectives, risk monitoring, skill endorsements, pull request translation, and comprehensive project audits.

Connexio's architecture follows a service-to-service authentication model where the backend services communicate securely using shared credentials. All services share a central database, with each service owning specific data tables. The frontend will be the final integration layer connecting users to all three backend services through a unified interface.
