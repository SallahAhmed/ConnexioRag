Connexio is a collaborative project platform that connects learners and builders to create real software projects in intelligent teams. It bridges the gap between education and real-world experience by providing a structured environment where users can form teams, manage projects, learn new skills, and build production-quality software together. The platform is designed to serve four main user personas: students who want hands-on project experience, early-career professionals looking to build their portfolios and network, educators who need a practical platform for teaching software development, and companies seeking to identify and recruit talented developers through real project work.

The platform consists of three integrated backend services working together. The Node.js backend handles core API operations including user authentication via JWT, project CRUD, task management, file uploads, friend connections, and posts. The Connexios RAG (Retrieval-Augmented Generation) engine powers intelligent chat by searching indexed documents, combining them with live project data, and generating context-aware answers. The MasarX Agent handles autonomous project management including task creation with human-in-the-loop approval, team matching using a weighted 6-factor algorithm, document generation for READMEs and retrospectives, risk monitoring, skill endorsements, pull request translation, and comprehensive project audits.

Connexio's architecture follows a service-to-service authentication model where the backend communicates with the RAG using an X-API-Key header and with MasarX using short-lived service JWTs. All three services share a PostgreSQL database on Neon.tech, with the RAG owning the projects, assets, chunks, and chat session tables, while MasarX owns user, task, and notification tables. The frontend will be the final integration layer connecting users to all three backend services through a unified interface.
