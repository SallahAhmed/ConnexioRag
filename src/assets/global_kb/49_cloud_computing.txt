Cloud computing delivers computing services including servers, storage, databases, networking, software, and analytics over the internet, enabling faster innovation, flexible resources, and economies of scale. Instead of owning and maintaining physical data centers, organizations rent access to computing resources from cloud providers and pay only for what they use. Cloud computing has become the default infrastructure model for most new technology projects and is essential knowledge for modern software developers.

The three main service models define the level of control and responsibility the customer has. Infrastructure as a Service (IaaS) provides virtual machines, storage, and networking resources that the customer configures and manages, similar to having a virtual data center. Examples include Amazon EC2, Google Compute Engine, and Azure Virtual Machines. Platform as a Service (PaaS) provides a complete development and deployment platform including runtime, database, and middleware, allowing developers to focus on code without managing infrastructure. Examples include Heroku, Google App Engine, and AWS Elastic Beanstalk. Software as a Service (SaaS) provides ready-to-use applications accessed through a web browser, with the provider managing everything. Examples include Google Workspace, Microsoft 365, and Salesforce.

The three major cloud providers each have their own ecosystems. Amazon Web Services (AWS) is the market leader with the broadest service portfolio including EC2 for compute, S3 for storage, RDS for databases, Lambda for serverless functions, and SageMaker for machine learning. Microsoft Azure integrates tightly with Microsoft enterprise tools and offers strong hybrid cloud capabilities. Google Cloud Platform (GCP) excels in data analytics, machine learning, and container services with Kubernetes originating from Google. Key cloud concepts include regions and availability zones which define where infrastructure is physically located. Scalability allows resources to automatically increase or decrease based on demand. Pay-as-you-go pricing means you only pay for actual usage. Managed services reduce operational overhead by having the provider handle maintenance, patching, and backups. Serverless computing lets you run code without provisioning servers, scaling automatically and charging only for compute time used. Containers and Kubernetes have become the standard for deploying and orchestrating applications in the cloud. The Connexios RAG is itself deployed on cloud infrastructure, using Hugging Face Spaces for hosting, Neon.tech for managed PostgreSQL with pgvector, and Upstash for managed Redis.
