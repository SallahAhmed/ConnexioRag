The Connexios RAG (Retrieval-Augmented Generation) is an intelligent knowledge engine that powers the platform's conversational AI assistant. It combines vector search over indexed documents with live data from the backend API to generate contextually relevant answers. The RAG processes every user query through a sophisticated pipeline that includes language detection, intent classification, knowledge base retrieval, relevance grading, and corrective RAG fallback to external sources when internal knowledge is insufficient.

The RAG supports bilingual conversation in English and Arabic with automatic language detection based on Unicode character ranges. It classifies user intent into seven workflow nodes: ONBOARDING for new user guidance, TEAM_FORMATION for team matching and recruitment questions, PHASE_TRANSITION for project phase advancement, BLOCKER for technical troubleshooting, MILESTONE_WARNING for schedule and deadline concerns, GENERAL for any project-related professional or technical questions, and OUT_OF_SCOPE for off-topic queries that are refused politely. Classification uses a three-tier approach: fast keyword matching for common patterns, a 50-character fast-path for short queries, and LLM-based classification for complex or ambiguous queries.

The RAG uses a tiered response strategy that optimizes cost and performance based on context value. Tier 0 handles OUT_OF_SCOPE queries with instant canned refusal using zero LLM calls. Tier 1 serves projectless sessions using the utility LLM model with a minimal system prompt and capped history. Tier 2 serves project sessions using the full generation model with complete RAG context, knowledge base search, CRAG fallback tools, and live backend data injection. Every request generates a JSON trace file for debugging and performance monitoring. The RAG also supports streaming responses via Server-Sent Events for real-time chat experiences.
