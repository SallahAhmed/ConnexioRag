Task management on Connexio is powered by the MasarX Agent, which can automatically create, assign, and track tasks throughout the project lifecycle. Tasks are the fundamental unit of work in the platform and each task has a comprehensive set of attributes including a title describing the work, a detailed description, an assigned team member who is responsible for completion, a current status (pending, in_progress, completed), a priority level (low, medium, high, critical), start date, and end date. Tasks can also be tagged with labels, linked to specific milestones, and associated with file attachments.

The MasarX Agent can intelligently distribute tasks across team members based on their skills, current workload, and availability. When a project sprint starts, the agent analyzes the project requirements and generates a set of tasks that cover all necessary work. These tasks are presented to the project owner for human-in-the-loop approval before being assigned to team members. This ensures that the AI-generated tasks are reviewed and validated by someone who understands the project context. Team members can update task status, add comments with progress updates, mark blockers, and attach completed work for review.

The task system integrates with the project dashboard which provides a real-time view of project progress. The dashboard shows task completion percentages, burndown charts for sprint tracking, individual team member workloads, upcoming deadlines, and potential risks such as overdue tasks or overloaded team members. The MasarX Monitor subgraph continuously tracks these metrics and can send alerts when it detects potential issues like a team member who is assigned too many tasks or a milestone that is at risk of being missed. Task history is preserved for retrospective analysis and skill endorsement calculations.
