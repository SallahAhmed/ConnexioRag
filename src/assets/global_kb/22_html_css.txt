HTML (HyperText Markup Language) and CSS (Cascading Style Sheets) are the foundational technologies for building web pages. HTML provides the structure and content of a page while CSS controls the visual presentation and layout. Together they form the core of frontend web development alongside JavaScript.

HTML uses elements defined by tags to structure content. Common HTML elements include headings from h1 to h6 for creating hierarchical titles, p for paragraphs, a for hyperlinks with href attributes pointing to URLs, img for images with src and alt attributes, ul and ol for unordered and ordered lists, table, tr, td, and th for tabular data, form, input, select, textarea, and button for interactive forms, and div and span for generic containers. Semantic HTML5 elements like header, nav, main, section, article, aside, and footer provide meaningful structure that improves accessibility and SEO. Good HTML practices include using proper heading hierarchy, providing descriptive alt text for images, using labels for form inputs, and maintaining valid markup.

CSS controls how HTML elements appear on screen. CSS can be applied inline, in embedded style tags, or in external stylesheet files linked from the HTML. CSS selectors target HTML elements by tag name, class, ID, attribute, or relationship to other elements. The cascade determines which styles apply when multiple rules target the same element, with more specific selectors and later declarations taking priority. The box model describes how every element is rendered as a box with content, padding, border, and margin areas. CSS Flexbox creates one-dimensional layouts with flexible alignment and distribution of space. CSS Grid creates two-dimensional layouts with rows and columns. Media queries enable responsive design by applying different styles based on screen size, resolution, and device characteristics. CSS custom properties (variables) enable consistent theming across a website.
