A Work Breakdown Structure (WBS) is a hierarchical decomposition of a project into smaller, more manageable components called work packages. It is one of the most important project planning tools because it transforms the broad project scope into specific, actionable units of work that can be estimated, assigned, tracked, and controlled. The WBS organizes the total scope of work in a tree structure where each descending level represents an increasingly detailed definition of the project work.

The top level of the WBS represents the final project deliverable. Each subsequent level breaks down the work into more detail. The lowest level consists of work packages that represent the smallest units of work that can be reliably estimated and assigned to a person or team. A well-constructed WBS follows several important rules. The 100% rule states that the WBS must capture all work required for the project at every level, including management and administrative activities. Mutually exclusive elements ensure no work package overlaps with another. The WBS should be outcome-oriented, focusing on deliverables rather than activities. Each work package should be able to be completed within a single reporting period, typically one to two weeks.

The WBS serves as the foundation for other project management processes. From it develop accurate cost estimates because each work package can be priced individually. The schedule is built by sequencing and allocating time to each work package. Resource allocation becomes clearer because specific skills can be assigned to specific work packages. Risk identification improves because risks can be assessed at the work package level. The WBS is typically visualized as an indented list or a tree diagram and is maintained throughout the project as scope changes.
