The MasarX Agent is Connexio's autonomous project management system built on a multi-agent AI architecture. It uses a supervisor-based system that routes incoming requests to one of several specialized sub-agents, each handling a specific domain of project management. The system maintains comprehensive state information covering routing, context, human-in-the-loop approval, knowledge retrieval, output generation, and risk monitoring.

The sub-agents include: The Task agent which creates and distributes tasks based on project requirements, with human-in-the-loop approval gates that require the project owner to review and approve task plans before they are assigned. The Team agent handles team member matching, onboarding new members with tailored guidance, and refining team recommendations based on feedback. The Documentation agent generates project README files, milestone documentation that captures phase completion details, and sprint retrospectives that summarize what the team accomplished and learned. The Monitoring agent continuously detects project risks by analyzing task completion rates, workload balance, and deadline adherence, and monitors team workload to prevent burnout.

The Translation agent translates pull requests and code changes between languages to support multilingual teams. The Skill Endorsement agent evaluates completed tasks and endorses team members for the skills they demonstrated. The Audit agent runs comprehensive project audits that combine documentation generation, risk detection, and team analysis into a single coordinated workflow. The MasarX Agent can be triggered either by webhook events from the backend such as user registration, project sprint start, or task completion, or by manual API requests. It supports both fully autonomous execution and human-in-the-loop workflows where critical actions require approval.
