The MasarX Agent is Connexio's autonomous project management system built on a LangGraph-based multi-agent architecture. It uses a supervisor graph that routes incoming requests to one of seven specialized subgraphs, each handling a specific domain of project management. The system maintains state through a comprehensive MasarXState object with 21 fields covering routing, context, invocation tracking, human-in-the-loop approval, RAG retrieval, output generation, and risk monitoring.

The seven subgraphs are: The Task subgraph which creates and distributes tasks based on project requirements, with human-in-the-loop approval gates that require the project owner to review and approve task plans before they are assigned. The Team subgraph handles team member matching, onboarding new members with tailored guidance, and refining team recommendations based on feedback. The Doc subgraph generates project README files, milestone documentation that captures phase completion details, and sprint retrospectives that summarize what the team accomplished and learned. The Monitor subgraph continuously detects project risks by analyzing task completion rates, workload balance, and deadline adherence, and monitors team workload to prevent burnout.

The PR Translator subgraph translates pull requests and code changes between languages to support multilingual teams. The Skill Endorsement subgraph evaluates completed tasks and endorses team members for the skills they demonstrated. The Audit subgraph runs comprehensive project audits that combine README generation, risk detection, and team analysis into a single coordinated workflow. The MasarX Agent can be triggered either by webhook events from the backend such as user.joined_platform, project.sprint_started, or task.completed, or by manual API requests. It supports both fully autonomous execution and human-in-the-loop workflows where critical actions require approval, using signed approval tokens with configurable expiration times.
